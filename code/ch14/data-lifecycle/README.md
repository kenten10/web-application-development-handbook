# 課題14.7: 個人データの削除・保持・エクスポート・同意の抜けを再現して塞ぐ (★★★)

## 目的

削除の伝播漏れ、保持期間の未実行、エクスポートへの他人のデータ混入、撤回された同意での配信という4件を再現し、所在一覧を入力にした実装へ差し替えると1件も残らず、かつ他の利用者のデータが巻き添えにならないことを確かめる。

## 開始地点

`starter/main.ts`（実行入口は `starter/report.ts`）

## 模範解答

`solution/main.ts`（実行入口は `solution/report.ts`）

## 実行・確認

```bash
pnpm --filter @handbook/ch14 exec tsx data-lifecycle/solution/report.ts
pnpm --filter @handbook/ch14 run test
```

## 安全上の注意

データはすべて架空の値であり、実在の個人を示すものではありません。プロセス外へは何も書き出しません。**本番のデータベースやバックアップに対して実行してはいけません。** どのデータをどこまで消すか、何を残す義務があるかの判断は、法務および専門家に確認してください（14.26、28.14、30.16）。
