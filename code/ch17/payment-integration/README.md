# 課題17.7: 決済連携の二重課金・返金超過・突合欠如を再現して塞ぐ (★★★)

## 目的

浮動小数点数による按分のずれ、タイムアウトを失敗として扱ったことによる二重課金、上限を検査しない部分返金の超過、突合を持たないための Webhook 欠落の見逃しという4件を再現し、実装を差し替えると1件も残らず、かつ正当な課金と返金は通り続けることを確かめる。

## 開始地点

`starter/main.ts`（実行入口は `starter/report.ts`）

## 模範解答

`solution/main.ts`（実行入口は `solution/report.ts`）

## 実行・確認

```bash
pnpm --filter @handbook/ch17 exec tsx payment-integration/solution/report.ts
pnpm --filter @handbook/ch17 run test
```

## 安全上の注意

`FakeGateway` はメモリ上の模擬であり、実在の決済事業者へは接続しません。実在の鍵・エンドポイント・カード情報は一切含まれていません。実際の決済 API を試す場合は、**必ずテスト環境の鍵だけ**を使ってください。本番の鍵を置いたまま演習すると、実際の課金や返金が発生します。カード情報の取り扱い範囲、返金の扱い、保存義務の判断は、決済事業者および法務へ確認してください（17.16、30.16）。
