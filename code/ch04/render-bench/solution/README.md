# 模範解答 — 課題4.1

`../index.solution.html`をブラウザで開き、Chrome DevToolsのPerformance記録中にBad、Better、Bestをそれぞれ実行します。

```bash
open code/ch04/render-bench/index.solution.html
```

画面上の`performance.measure`値はJavaScript区間の参考値です。評価ではPerformanceパネルの`Recalculate Style`、`Layout`、`Paint`、`Composite Layers`を確認します。倍率は端末やブラウザで変わるため、固定値を模範解答にしません。
